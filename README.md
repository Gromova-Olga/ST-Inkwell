# 🖋️ ST Inkwell (Unified Extensions)

**ST Inkwell** — это удобный инструмент для SillyTavern, объединивший в себе функционал трех моих расширений для работы с контентом: управления лорбуками, извлечения текста и архивации чатов. Теперь всё необходимое для ведения лора и сохранения истории ваших приключений находится в одном удобном интерфейсе.

Это обновление полностью переосмысляет рабочий процесс, делая интерфейс чище, а управление — профессиональнее.

## 🛠️ Состав комбайна

### 📁 1. ST Lorebook Folders & Binder (Управление лорбуками)

Настоящая магия автоматизации. Группируйте лорбуки по папкам (и подпапкам) и намертво привязывайте их к конкретным чатам. Как только вы открываете диалог, нужные лорбуки автоматически встают в "Активные миры для всех чатов", а при выходе — выгружаются. Больше никакой рутины с галочками!

* 📁 **Продвинутая иерархия:** Бесконечная вложенность папок («матрешка») без ограничений. При удалении папки расширение корректно очищает все вложенные элементы.
* 🔍 **Навигация и Контроль:** Живой поиск и мгновенная фильтрация лорбуков и папок по ключевым словам. Специальный **Компактный режим** для тех, у кого сотни лорбуков. Полная поддержка **Drag & Drop**.
* 🎨 **Кастомизация и UX:** Цветовая маркировка папок и плавные анимации открытия/закрытия списков.
* 📱 **Мобильная адаптация:** Панель автоматически подстраивается под экраны смартфонов.
* 🛡️ **Сохранность данных (Backup):** Возможность скачать всю структуру ваших папок в `.json` и загрузить её обратно.

---

### 📖 2. ST-Lorebook-Extractor (Извлечение текста)

Создано для быстрого извлечения «чистого» текста из ваших лорбуков, отсекая техническую информацию (ключи, триггеры, веса). Вы получаете только суть: заголовки и текст записей.

#### Ключевые возможности:

* ✨ **Чистый экспорт:** Только названия и контент записей.
* ✅ **Выборочное извлечение:** Удобный список с чекбоксами позволяет выбрать только нужные записи.
* 📋 **Быстрое копирование/экспорт:** Выгружайте готовый текст в буфер обмена или скачивайте в формате `.txt` в один клик.

---

### 📋 3. ST-Chat-Exporter (Экспорт чатов)

Позволяет гибко экспортировать, фильтровать и сохранять логи ваших чатов для архивации или удобного чтения вне браузера.

#### Особенности:

* 🎯 **Гибкий выбор сообщений:** Экспортируйте весь чат, заданный диапазон (например, с 10 по 50) или конкретные сообщения через запятую.
* 👤 **Фильтрация по автору:** Выгрузка только реплик пользователя или только ответов бота.
* 🔍 **Умный поиск:** Встроенный поиск по тексту с подсветкой найденных слов прямо в окне предпросмотра.
* 💾 **Разные форматы экспорта:**
    * **TXT:** Чистый текст (с возможностью включить отступы, имена, номера сообщений и таймстампы).
    * **HTML:** Красиво оформленная веб-страница для комфортного чтения.

#### FAQ (Частые вопросы по экспорту):

**Q: Как быстро открыть окно экспортёра?**
**A:** Нажмите на специальную иконку ящика (🧰) в заголовке любого сообщения в чате или верхнем баре самой таверны.

## 🛠️ Установка / Обновление

1.  Зайдите в **Extensions** -> **Install Extension**.
2.  Используйте ссылку на репозиторий: `https://github.com/Gromova-Olga/ST-Inkwell`
3.  Если расширение уже установлено — нажмите **Update** во вкладке расширений.
